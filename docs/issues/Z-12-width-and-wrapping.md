## Goal

- `Zat::Width`: dependency-free, Ractor-safe display width.
- `Zat::Text`: ANSI-aware line wrapping.

## Context

The `unicode-display_width` gem fails in a Ractor (`EmojiSupport.recommended` writes a class-level instance variable), so the width table is our own.

## Rules

- **`Zat::Width`:**
  - The range table (width 0, 1 or 2) is generated by `script/gen_width_table.rb` from Unicode's `EastAsianWidth.txt` and `emoji-data.txt`. The Unicode version matches Ruby 4.1's.
  - The result is a frozen array of integers, looked up with `bsearch`.
  - Fast path for `ascii_only?`.
  - ZWJ emoji clusters count as 2.
- **`Text.width(str)`:** ignores SGR and OSC 8.
- **`Text.wrap(str, width, indent:)`:**
  - wraps at spaces;
  - hard-breaks words longer than the width;
  - closes and reopens active styles at each break.

## Acceptance criteria

- [ ] Tests with accents, CJK, ZWJ emoji, and escapes in the middle of a word
- [ ] Seeded property test: no line exceeds `columns`
- [ ] Styles survive line breaks
- [ ] The table is shareable and its Unicode version is documented
